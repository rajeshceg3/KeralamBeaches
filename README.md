# Kerala: Five shores, one long light

Five original, freely orbitable illustrations: Kovalam's lighthouse, Varkala's laterite cliffs, the Alappuzha backwaters, Marari's fishing shore, and Bekal Fort. Place stories link to Kerala Tourism. These are simplified illustrations, not measured reconstructions or maps. Alappuzha explicitly depicts inland backwaters rather than its beach.

- Drag, pinch, wheel, arrow keys, Home and Reset view.
- Independent motion, dark/light UI, opt-in synthesized tide. No field-recording claim.
- Five source-linked stories; a guide and source colophon.
- Explored count persists locally. Sound never starts automatically.
- Original scrollytelling source preserved in `legacy/`.

`npm ci && npm run build`. `WIDTH=390 npm run verify` runs the full interaction matrix. For bounded local runs, `THEME=0` or `THEME=1` runs one theme. CI runs both themes at390 and1440. `verification/` contains executed interaction, contrast and audio capture scripts. Human audio listening remains unsigned.

Hosting: GitHub is the source of truth; free Cloudflare Pages is the current target while Vercel is capped. Do not replace the old deployment until a new mobile floor and hosted checks pass.
